<h1 style="font-size:29px;line-height:1.25;margin:14px 0 6px;">八步建立一份测量不确定度预算</h1>
<p style="color:#5b6675;font-size:15px;margin:0 0 6px;">按 GUM 搭预算，把评审员真正会复核的那几步算术写清楚。</p>
<p style="color:#8a94a3;font-size:12px;margin:0 0 16px;">更新于 2026 年 11 月 13 日 · 约 9 分钟 · 写给一线实验室与质量团队</p>
<div style="background:#eef4ff;border-left:4px solid #1e4d8b;border-radius:8px;padding:14px 18px;margin:0 0 22px;"><p style="margin:0 0 6px;font-size:11px;font-weight:700;letter-spacing:.6px;color:#1e4d8b;text-transform:uppercase;">短答案</p><p style="margin:0;font-size:15px;">不确定度预算是一份成文的模型，说明结果里的「不确定」从哪里来：定义被测量和测量模型 y = f(x₁ … xₙ)，把每个显著来源量化成<b>标准</b>不确定度，用灵敏系数合成（平方和开方，必要时加协方差项），再乘以包含因子 k（通常取 2）得到扩展不确定度 U，并连同单位、k 和包含概率一起报告。按 ISO/IEC 17025:2017（7.6），对所出具报告的方法都必须评定；任何合格／不合格结论都需要书面判定规则（7.8.6）。</p></div>
<div style="border:1px solid #e6e9ef;border-radius:8px;padding:12px 16px;margin:0 0 24px;"><p style="margin:0 0 6px;font-size:12px;font-weight:700;color:#5b6675;">本页目录</p><ol style="margin:0;padding-left:20px;font-size:13.5px;"><li><a href="#s1" style="color:#2563eb;">八个步骤</a></li><li><a href="#s2" style="color:#2563eb;">一个小算例</a></li><li><a href="#s3" style="color:#2563eb;">不确定度不等于判定规则</a></li><li><a href="#where-it-goes-wrong" style="color:#2563eb;">现场最容易踩的坑</a></li><li><a href="#faq" style="color:#2563eb;">常见问题</a></li></ol></div>
<h2 id="s1" style="font-size:20px;margin-top:30px;margin-bottom:8px;">八个步骤</h2>
<ol style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:9px;"><b>1. 定义被测量和模型。</b>写清报告的究竟是哪个量、什么单位、哪个范围和基质，再写出产出它的方程。没有模型的预算，只是一列无法检查完整性的数字。</li><li style="margin-bottom:9px;"><b>2. 列出来源。</b>仪器校准、分辨率、重复性、环境条件、样品制备、操作人员、标准物质纯度、方法偏倚、修约，以及任何施加的修正值。一张鱼骨图，或「来源 → 量化方式 → 数值」的简表就够。</li><li style="margin-bottom:9px;"><b>3. 每项量化成标准不确定度 u(xᵢ)。</b><b>A 类</b>来自统计（例如重复测量的 s/√n）；<b>B 类</b>来自证书、规格、分辨率或经验。校准证书给出扩展不确定度 U 且 k = 2 时，标准不确定度是 U / 2——把 U 直接填进去会把这个分量放大一倍。</li><li style="margin-bottom:9px;"><b>4. 选分布和除数。</b>半宽为 a 的矩形（均匀）分布给出 u = a/√3，三角分布为 a/√6，按给定包含概率报出的正态分布为 u = U/k。数显分辨率 δ 通常按 ±δ/2 的矩形分布处理，即 u = δ/(2√3)。写明所用除数——评审员会问。</li><li style="margin-bottom:9px;"><b>5. 处理相关性。</b>两个分量若共用同一个参考（例如样品和空白用同一台校准器），就不独立；要加协方差项或重构模型。悄悄把相关输入当独立处理，是不确定度被低估的常见原因。</li><li style="margin-bottom:9px;"><b>6. 合成。</b>u_c(y) = √[ Σ (∂f/∂xᵢ)² u²(xᵢ) + 2 Σ 协方差项 ]。∂f/∂xᵢ 是灵敏系数。简单加和模型里它们等于 1；比值、幂次或对数模型里，它们会实质改变结果。</li><li style="margin-bottom:9px;"><b>7. 自由度与 k。</b>若 A 类分量数据有限，用 Welch–Satterthwaite 公式求有效自由度 ν_eff，按目标包含概率从 t 分布取 k；否则 k = 2 是约 95% 包含概率的常规选择。</li><li style="margin-bottom:9px;"><b>8. 正确报告。</b>写明结果、U、单位、k、包含概率和 U 的获得方式，例如「12.43 mm ± 0.20 mm，k = 2（约 95%），按 GUM 评定」。若作出符合性声明，指明所用判定规则，并确认已在合同评审时与客户约定（7.1.3）。</li></ol>
<h2 id="s2" style="font-size:20px;margin-top:30px;margin-bottom:8px;">一个小算例</h2>
<p style="margin:0 0 12px;">用一把已校准的千分尺测长度。校准证书给出 U = 0.20 mm、k = 2，故 u₁ = 0.20/2 = <b>0.100 mm</b>。仪器分辨率为 0.01 mm，故 u₂ = 0.01/(2√3) ≈ <b>0.0029 mm</b>。十次重复读数得 s = 0.09 mm，而报告值是 3 次读数的均值，故 u₃ = 0.09/√3 ≈ <b>0.052 mm</b>。</p>
<ul style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:7px;">u_c = √(0.100² + 0.0029² + 0.052²) ≈ <b>0.113 mm</b>。</li><li style="margin-bottom:7px;">U = k × u_c = 2 × 0.113 ≈ <b>0.23 mm</b>，报告时写明 k = 2 和包含概率。</li><li style="margin-bottom:7px;">注意主导项是校准分量。再多测几次对报告不确定度帮助不大——换更好的校准，或对已知偏倚做修正，才有用。</li><li style="margin-bottom:7px;">如果 0.09 mm 的重复性已经包含了分辨率影响（同一台仪器上读数时通常如此），就不要再把 u₂ 加一遍——那是重复计算。</li></ul>
<p style="background:#fff8e8;border:1px solid #f0d9a0;border-radius:8px;padding:11px 15px;margin:0 0 16px;font-size:14px;"><b>实务提示。</b> 最常见的不符合项不是平方根算错，而是一份把样品制备、环境效应和方法偏倚整体忽略、然后原样复制到范围内每个被测量上的预算。预算属于一个测量模型，不属于一个文档模板。</p>
<h2 id="s3" style="font-size:20px;margin-top:30px;margin-bottom:8px;">不确定度不等于判定规则</h2>
<p style="margin:0 0 12px;">不确定度描述测得值里有多少疑问；判定规则描述在对限制作符合性结论时如何使用这个疑问。结果为 99 ± 2、限值为 100 时，在共担风险的简单接受规则下可能判合格，在带保护带的严格接受规则下可能判不合格。条款 7.8.6 要求规则成文并沟通，7.1.3 把与客户的约定放在合同评审。报告写「合格」却不写规则，或写了一条没人同意过的规则，即使数字算对了也是不符合项。</p>
<p style="margin:0 0 12px;">同时别忘了计量溯源链（6.5）：校准器的不确定度会流进你的预算，所以一张证书上写明的不确定度若大于你声称的测量能力，评审员一眼就会看出矛盾。</p>
<h2 id="where-it-goes-wrong" style="font-size:20px;margin-top:30px;margin-bottom:8px;">现场最容易踩的坑</h2>
<p style="margin:0 0 11px;">把证书上的扩展不确定度 U（k = 2）直接当标准不确定度，忘记除以 k。</p>
<p style="margin:0 0 11px;">分辨率算两遍：一次单列，另一次又含在同一台仪器上得到的重复性标准差里。</p>
<p style="margin:0 0 11px;">只报「± 0.05」，不写 k、不写包含概率、不写单位、不写怎么来的。</p>
<p style="margin:0 0 11px;">一份预算复制到所有方法、基质和浓度范围，或把样品制备与方法偏倚不加论证地写成「可忽略」。</p>
<p style="margin:0 0 11px;">作出合格／不合格结论却没有书面判定规则，或用了客户从未同意过的保护带。</p>
<h2 id="faq" style="font-size:20px;margin-top:30px;margin-bottom:8px;">常见问题</h2>
<p style="margin:0 0 10px;"><b>ISO/IEC 17025 哪一条要求测量不确定度？</b><br>条款 7.6 要求实验室对检测和校准评定测量不确定度，包括识别贡献分量并采用适当的估计方法。7.8.6 管符合性声明与判定规则，6.5 管计量溯源性。现行版本是 ISO/IEC 17025:2017，没有 2025 版。</p>
<p style="margin:0 0 10px;"><b>必须一律取 k = 2 吗？</b><br>不必。有效自由度较大时，k = 2 是约 95% 包含概率的常规选择。若 A 类估计只基于少量观测，有效自由度（Welch–Satterthwaite）可能支持从 t 分布取更大的 k。无论取哪个，都要写明它和包含概率。</p>
<p style="margin:0 0 10px;"><b>GUM 是唯一被接受的方法吗？</b><br>不是。GUM 不确定度框架最常用；蒙特卡洛传播（JCGM 101）适用于非线性模型或非正态输入分布；某些行业使用基于方法性能和内部质控的、经验证的自上而下方法。用哪一种都要写明模型并论证输入。</p>
<p style="margin:0 0 10px;"><b>能用校准证书的不确定度当整份预算吗？</b><br>只有在能论证不存在其他显著贡献时才可以——对检测实验室而言这很少成立。样品制备、基质效应、重复性、环境条件和方法偏倚通常都有贡献。证书给出的只是一个标准不确定度分量，不是预算。</p>
