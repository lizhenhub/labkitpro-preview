<h1 style="font-size:29px;line-height:1.25;margin:14px 0 6px;">Cpk 和 Ppk 真正的差别，只在于你用了哪一个标准差</h1>
<p style="color:#5b6675;font-size:15px;margin:0 0 6px;">均值相同、规格限相同，标准差不同。这两个指数之间的差距，是在告诉你过程有没有漂移。</p>
<p style="color:#8a94a3;font-size:12px;margin:0 0 16px;">更新于 2026 年 11 月 13 日 · 约 7 分钟 · 写给一线实验室与质量团队</p>
<div style="background:#eef4ff;border-left:4px solid #1e4d8b;border-radius:8px;padding:14px 18px;margin:0 0 22px;"><p style="margin:0 0 6px;font-size:11px;font-weight:700;letter-spacing:.6px;color:#1e4d8b;text-transform:uppercase;">短答案</p><p style="margin:0;font-size:15px;">Cpk 和 Ppk 用同一组规格限、同一个均值，唯一的差别是标准差。<b>Cpk</b> 用组内变差（由 R̄/d2 或 s̄/c4 估计），也就是短期的、普通原因造成的波动；<b>Ppk</b> 用全部数据的整体样本标准差，其中还包含了组与组之间的漂移。过程稳定时两者接近；差距很大并不是算错了，而是在提醒你：取数这段时间里，过程本身移动过。</p></div>
<div style="border:1px solid #e6e9ef;border-radius:8px;padding:12px 16px;margin:0 0 24px;"><p style="margin:0 0 6px;font-size:12px;font-weight:700;color:#5b6675;">本页目录</p><ol style="margin:0;padding-left:20px;font-size:13.5px;"><li><a href="#s1" style="color:#2563eb;">两个公式摆在一起看</a></li><li><a href="#s2" style="color:#2563eb;">带真实数字的算例</a></li><li><a href="#s3" style="color:#2563eb;">什么场合报哪一个</a></li><li><a href="#s4" style="color:#2563eb;">动手计算前的四项检查</a></li><li><a href="#where-it-goes-wrong" style="color:#2563eb;">现场最容易踩的坑</a></li><li><a href="#faq" style="color:#2563eb;">常见问题</a></li></ol></div>
<h2 id="s1" style="font-size:20px;margin-top:30px;margin-bottom:8px;">两个公式摆在一起看</h2>
<p style="margin:0 0 12px;">两个指数都是把「过程均值到最近规格限的距离」拿去和三个标准差比较。变的只有分母那个标准差：</p>
<div style="overflow-x:auto;margin:0 0 16px;"><table style="width:100%;border-collapse:collapse;font-size:13.5px;"><thead><tr><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">指数</th><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">用的标准差</th><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">回答的问题</th></tr></thead><tbody><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">Cp = (USL − LSL) / 6σ<sub>组内</sub></td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">组内变差</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">如果居中，这个过程装得下吗？</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">Cpk = min[(USL − μ), (μ − LSL)] / 3σ<sub>组内</sub></td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">组内变差</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">按现在的实际居中位置，装得下吗？</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">Pp = (USL − LSL) / 6s<sub>整体</sub></td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">整体样本 s</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">这一整批实际装下了吗？</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">Ppk = min[(USL − μ), (μ − LSL)] / 3s<sub>整体</sub></td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">整体样本 s</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">这一整批按实际居中位置，装下了吗？</td></tr></tbody></table></div>
<p style="background:#fff8e8;border:1px solid #f0d9a0;border-radius:8px;padding:11px 15px;margin:0 0 16px;font-size:14px;"><b>实务提示。</b> Cp 和 Pp 完全不考虑居中。一个过程贴着上规格限跑，Cp 照样可以很漂亮。永远把指数和均值、直方图一起读，不要把它当成一张单独的及格证。</p>
<h2 id="s2" style="font-size:20px;margin-top:30px;margin-bottom:8px;">带真实数字的算例</h2>
<p style="margin:0 0 12px;">一根车削轴规格为 10.00 ± 0.20 mm，即 LSL = 9.80、USL = 10.20。取 25 个子组，每组 5 件。总均值 μ = 10.02，由 R̄/d2 得到的组内标准差为 0.030，全部 125 个数据的整体标准差为 0.055。</p>
<p style="margin:0 0 12px;"><b>Cpk</b> = min[(10.20 − 10.02) / (3 × 0.030), (10.02 − 9.80) / (3 × 0.030)] = min[2.00, 2.44] = <b>2.00</b>。</p>
<p style="margin:0 0 12px;"><b>Ppk</b> = min[(10.20 − 10.02) / (3 × 0.055), (10.02 − 9.80) / (3 × 0.055)] = min[1.09, 1.33] = <b>1.09</b>。</p>
<p style="margin:0 0 12px;">算术没有问题。短期能力是 2.00，整体表现只有 1.09，原因是子组均值在游走——刀具磨损、换班、开机热漂移，或者两批材料。只报 2.00 才是真正的错误。</p>
<h2 id="s3" style="font-size:20px;margin-top:30px;margin-bottom:8px;">什么场合报哪一个</h2>
<ul style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:7px;"><b>初次提交 / PPAP：</b>客户通常要求初始批次 Ppk ≥ 1.67，因为它反映实际发生的一切。这是客户或 AIAG PPAP 的惯例，不是 ISO 9001 或 IATF 16949 的条款要求。</li><li style="margin-bottom:7px;"><b>量产监控：</b>Cpk ≥ 1.33 是最常见的合同目标，同样属于客户要求，而不是标准里写着的一行字。</li><li style="margin-bottom:7px;"><b>两个一起报：</b>差距本身就是诊断信息。Cpk ≈ Ppk，说明普通原因占主导、过程可预测；Cpk 明显更大，就先去找组间的特殊原因，再谈能力指数。</li><li style="margin-bottom:7px;"><b>两个都别报：</b>过程不稳定，或数据明显非正态时，能力指数只是一个没有模型支撑的数字。先稳定过程，或采用变换／非正态方法并写明用的是哪一种。</li></ul>
<h2 id="s4" style="font-size:20px;margin-top:30px;margin-bottom:8px;">动手计算前的四项检查</h2>
<ol style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:9px;"><b>先查测量系统。</b>如果量具 R&amp;R 相对公差偏大，你测到的散布有一部分属于量具，不属于过程。</li><li style="margin-bottom:9px;"><b>合理子组。</b>同一条件下做出来的件放进一个子组；否则组内标准差会被你正想抓的漂移污染。</li><li style="margin-bottom:9px;"><b>数据量要够。</b>用 8 个值算 Cpk 只是置信区间很宽的点估计。常用下限约为 25 个子组／100 个数据；如果决策依赖这个数，应连同其不确定度一起报告。</li><li style="margin-bottom:9px;"><b>图和限要配对。</b>控制限来自过程数据，规格限来自客户。把规格线画在 X̄ 图上当控制限，是车间里最常见的一个错误。</li></ol>
<h2 id="where-it-goes-wrong" style="font-size:20px;margin-top:30px;margin-bottom:8px;">现场最容易踩的坑</h2>
<p style="margin:0 0 11px;">用整体样本标准差去算 Cpk。你会得到两个 Ppk，还丢掉了唯一能区分短期能力与长期漂移的信号。</p>
<p style="margin:0 0 11px;">在不稳定的过程上报 Cpk。指数假设分布稳定可预测；控制图失控时，被推翻的是前提，不只是那个数字。</p>
<p style="margin:0 0 11px;">把 1.33 当成法规。它只是广泛使用的客户目标。设定接收阈值前，先查合同、控制计划和顾客特殊要求。</p>
<p style="margin:0 0 11px;">把不同班次、不同模腔的 Cpk 求平均，而不是分流程看——两条各自健康、却分列均值两侧的流程，会把一个双峰烂摊子藏起来。</p>
<h2 id="faq" style="font-size:20px;margin-top:30px;margin-bottom:8px;">常见问题</h2>
<p style="margin:0 0 10px;"><b>Cpk 一定比 Ppk 大吗？</b><br>通常是，因为整体变差＝组内变差＋组间移动。但这不是数学上的保证：子组形态特殊时，整体估计也可能小于组内估计。把差距当诊断线索，不要当定律。</p>
<p style="margin:0 0 10px;"><b>Cpk 多少算好？</b><br>取决于合同与风险。1.33 是量产最常见的目标，初始或安全特性常被要求 1.67；这两个数字都不出现在 ISO 9001 或 IATF 16949 里。安全或受监管特性以顾客特殊要求为准。</p>
<p style="margin:0 0 10px;"><b>Cpk 可以是负数吗？</b><br>可以。过程均值一旦跑出规格限，到该限的距离为负，取最小值后就是负数。它表示过程分布的中心已经在产出超差品，不只是尾部有风险。</p>
<p style="margin:0 0 10px;"><b>提交时 Cpk 和 Ppk 都要给吗？</b><br>多数汽车客户要求提交批次的初始过程性能指数（Ppk），以及过程稳定后的能力指数（Cpk）。查提交等级和顾客特殊要求——要哪个指数、下限多少，是合同约定，不是通用规则。</p>
