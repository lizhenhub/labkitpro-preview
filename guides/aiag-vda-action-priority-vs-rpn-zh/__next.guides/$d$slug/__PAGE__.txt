<h1 style="font-size:29px;line-height:1.25;margin:14px 0 6px;">AIAG-VDA FMEA：为什么用行动优先级取代 RPN（做法要怎么改）</h1>
<p style="color:#5b6675;font-size:15px;margin:0 0 6px;">同一个 RPN 可能藏着两种完全不同的风险。AP 表是查表，不是乘法。</p>
<p style="color:#8a94a3;font-size:12px;margin:0 0 16px;">更新于 2026 年 11 月 13 日 · 约 7 分钟 · 写给一线实验室与质量团队</p>
<div style="background:#eef4ff;border-left:4px solid #1e4d8b;border-radius:8px;padding:14px 18px;margin:0 0 22px;"><p style="margin:0 0 6px;font-size:11px;font-weight:700;letter-spacing:.6px;color:#1e4d8b;text-transform:uppercase;">短答案</p><p style="margin:0;font-size:15px;">在 AIAG-VDA 2019 FMEA 手册中，风险优先数 RPN（S × O × D）被<b>行动优先级 AP</b> 取代：H／M／L 由严重度、频度、探测度的组合在官方表格中查出，既不是乘积，也不是加权分数。改的原因很直接——一个严重度高、频度中等、探测良好的失效，可能与一个无关紧要但很难探到的失效拿到同一个 RPN，而两者应有的行动完全不同。</p></div>
<div style="border:1px solid #e6e9ef;border-radius:8px;padding:12px 16px;margin:0 0 24px;"><p style="margin:0 0 6px;font-size:12px;font-weight:700;color:#5b6675;">本页目录</p><ol style="margin:0;padding-left:20px;font-size:13.5px;"><li><a href="#s1" style="color:#2563eb;">让 RPN 出局的那个算例</a></li><li><a href="#s2" style="color:#2563eb;">AP 怎么用才对</a></li><li><a href="#s3" style="color:#2563eb;">AP 在七步法里的位置</a></li><li><a href="#where-it-goes-wrong" style="color:#2563eb;">现场最容易踩的坑</a></li><li><a href="#faq" style="color:#2563eb;">常见问题</a></li></ol></div>
<h2 id="s1" style="font-size:20px;margin-top:30px;margin-bottom:8px;">让 RPN 出局的那个算例</h2>
<p style="margin:0 0 12px;">两行在旧方法下都是 120，所以「超过 100 就行动」的阈值规则会把它们一模一样地处理。改用 AIAG-VDA AP 表按 S/O/D 查表：(10, 4, 3) 落在高严重度区间，返回 H；(3, 4, 10) 落在低严重度区间，返回 L——同样的 RPN，两种完全不同的行动。乘法被弃用，原因就在这里。</p>
<p style="margin:0 0 12px;">RPN 还有第二个缺陷：它不是顺序量表。乘积之间的间隔不均匀，许多不同的 S/O/D 组合会得到同一个数，团队还能靠把探测度削掉一分来「改善」RPN，而真实风险一点没降。</p>
<div style="overflow-x:auto;margin:0 0 16px;"><table style="width:100%;border-collapse:collapse;font-size:13.5px;"><thead><tr><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">失效模式</th><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">S</th><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">O</th><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">D</th><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">RPN = S×O×D</th><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">官方表查出的 AP</th></tr></thead><tbody><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">制动功能丧失（安全、特殊特性）</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">10</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">4</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">3</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">120</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">H — 需采取行动（或留下书面理由）</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">不可见表面的外观划伤</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">3</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">4</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">10</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">120</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">L — 监视即可</td></tr></tbody></table></div>
<h2 id="s2" style="font-size:20px;margin-top:30px;margin-bottom:8px;">AP 怎么用才对</h2>
<ol style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:9px;">S 按失效的<b>后果</b>在团队约定的 1–10 量表上打分。严重度属于功能及其后果，不属于你的检验有多好。</li><li style="margin-bottom:9px;">O 按<b>失效原因</b>在现有预防控制下的发生频度打分；D 按现有探测控制在流出前发现该原因或失效模式的能力打分。</li><li style="margin-bottom:9px;">把 S/O/D 拿到官方 AP 表里查 H／M／L。不要取平均、不要相乘、不要自造权重——查表就是方法。</li><li style="margin-bottom:9px;">H：采取行动，或书面说明为何无法行动；M：应考虑行动；L：监视即可。有些组织和客户要求每一条 H 都必须行动——查顾客特殊要求。</li><li style="margin-bottom:9px;">记录建议措施、责任人、完成日期、完成证据和重新打分后的 S/O/D，再重新推导 AP。没有重打分栏的 FMEA 只是一张快照，不是活文件。</li></ol>
<p style="background:#fff8e8;border:1px solid #f0d9a0;border-radius:8px;padding:11px 15px;margin:0 0 16px;font-size:14px;"><b>实务提示。</b> 严重度只有在设计或过程功能改变、后果本身变轻时才可能下降。加相机、加传感器、加一道复检，降的是探测度，不是严重度。如果团队在加了检验之后报出更低的 S，打分就错了。</p>
<h2 id="s3" style="font-size:20px;margin-top:30px;margin-bottom:8px;">AP 在七步法里的位置</h2>
<p style="margin:0 0 12px;">AIAG-VDA 方法的顺序是：策划与准备 → 结构分析 → 功能分析 → 失效分析（后果／模式／原因的失效链）→ 风险分析（S、O、D、AP）→ 优化（措施与再评估）→ 结果文件化。AP 位于风险分析，用来驱动优化，它不是给零件打的最终分数。</p>
<p style="margin:0 0 12px;">设计 FMEA 与过程 FMEA 是连着的：DFMEA 识别出的特殊特性必须流入 PFMEA，再进入控制计划，并配上相应控制方法和反应计划。客户审核发现「特殊特性在 FMEA 里有、控制计划里没有」时，AP 怎么争都没意义——闭环压根没合上。IATF 16949 由国际汽车工作组发布，不是 ISO 标准；采用哪一版 FMEA 参考资料，以顾客特殊要求为准。</p>
<h2 id="where-it-goes-wrong" style="font-size:20px;margin-top:30px;margin-bottom:8px;">现场最容易踩的坑</h2>
<p style="margin:0 0 11px;">AP 和 RPN 都算，最后还是按 RPN 排序。这恰好把 AP 想解决的问题又请了回来。</p>
<p style="margin:0 0 11px;">靠加强探测控制来降严重度，或者为了让 H 行变成 M 而重打 S。</p>
<p style="margin:0 0 11px;">每一条 H 的措施栏都写「增加检验」。对高严重度失效模式，有意义的是预防（设计或过程变更）。</p>
<p style="margin:0 0 11px;">DFMEA、PFMEA 与控制计划之间的特殊特性链断着，或措施完成后从不重新打分。</p>
<p style="margin:0 0 11px;">凭记忆引用 AP 表。用客户要求的那版手册里的正式表格；H/M/L 边界是具体组合，不是一条公式。</p>
<h2 id="faq" style="font-size:20px;margin-top:30px;margin-bottom:8px;">常见问题</h2>
<p style="margin:0 0 10px;"><b>AIAG-VDA 2019 下还能用 RPN 吗？</b><br>协调后的 AIAG-VDA 方法用行动优先级而不是 RPN。部分客户、历史内部程序和基于旧版 SAE J1739 的系统仍会要求 RPN——按顾客特殊要求执行，不要在同一份分析里混用两套打分体系。</p>
<p style="margin:0 0 10px;"><b>H、M、L 到底是什么意思？</b><br>它们是行动优先级，不是风险排名。H 表示需要行动（或书面说明不行动的理由），M 表示应考虑行动，L 表示可采取行动、也可接受风险。确切表述以及是否强制行动，来自顾客特殊要求。</p>
<p style="margin:0 0 10px;"><b>AP 低的条目也可能必须行动吗？</b><br>会。严重度极高、法规要求、特殊特性和顾客特殊要求都可能不管 AP 字母而强制行动。AP 是 FMEA 内部的排序工具，不能替代这些义务。</p>
<p style="margin:0 0 10px;"><b>ISO 9001:2026 要求做 FMEA 吗？</b><br>不要求。FMEA 不是 ISO 9001 的要求；它通过 IATF 16949 和汽车行业顾客特殊要求被期待，在其他场合也可作为基于风险的思维工具自愿使用。</p>
