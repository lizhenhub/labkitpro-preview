<h1 style="font-size:29px;line-height:1.25;margin:14px 0 6px;">GR&amp;R：10% / 30% 阈值真正意味着什么（以及不意味着什么）</h1>
<p style="color:#5b6675;font-size:15px;margin:0 0 6px;">%GRR、可区分类别数、公差占比、ANOVA 与 X̄-R 方法——以及为什么一份「合格」的研究也可能毫无用处。</p>
<p style="color:#8a94a3;font-size:12px;margin:0 0 16px;">更新于 2026 年 11 月 13 日 · 约 7 分钟 · 写给一线实验室与质量团队</p>
<div style="background:#eef4ff;border-left:4px solid #1e4d8b;border-radius:8px;padding:14px 18px;margin:0 0 22px;"><p style="margin:0 0 6px;font-size:11px;font-weight:700;letter-spacing:.6px;color:#1e4d8b;text-transform:uppercase;">短答案</p><p style="margin:0;font-size:15px;">%GRR 是观测到的总变差中归属于测量系统的那一份。AIAG MSA 参考手册的惯用分档是：<b>低于 10% 可接受</b>、<b>10–30% 视用途／成本／客户有条件接受</b>、<b>高于 30% 需要改进</b>。这是行业惯例，不是 ISO 条款。要和可区分类别数 ndc（通常要求 ≥ 5）、公差占比，以及研究所用零件是否真的覆盖了过程变差一起读。</p></div>
<div style="border:1px solid #e6e9ef;border-radius:8px;padding:12px 16px;margin:0 0 24px;"><p style="margin:0 0 6px;font-size:12px;font-weight:700;color:#5b6675;">本页目录</p><ol style="margin:0;padding-left:20px;font-size:13.5px;"><li><a href="#s1" style="color:#2563eb;">一份研究能给出哪些数</a></li><li><a href="#s2" style="color:#2563eb;">单个结果本身不是结论</a></li><li><a href="#s3" style="color:#2563eb;">结果落在边缘时怎么办</a></li><li><a href="#where-it-goes-wrong" style="color:#2563eb;">现场最容易踩的坑</a></li><li><a href="#faq" style="color:#2563eb;">常见问题</a></li></ol></div>
<h2 id="s1" style="font-size:20px;margin-top:30px;margin-bottom:8px;">一份研究能给出哪些数</h2>
<p style="margin:0 0 12px;">经典设计是 <b>10 个零件 × 3 名操作员 × 3 次重复</b>，随机化测量，零件选取要覆盖正常过程范围。ANOVA 方法优于较老的 X̄-R（极差）法，因为它能估计操作员与零件的交互作用，而不是把它折进残差里。</p>

<h2 id="s2" style="font-size:20px;margin-top:30px;margin-bottom:8px;">单个结果本身不是结论</h2>
<ul style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:7px;"><b>零件选错，研究照样能「合格」。</b>十个零件若全来自同一个紧密批次，过程变差被低估，%GRR 会显得更差；若刻意挑了比生产范围宽得多的零件，%GRR 又会好于现实。零件要代表过程，不是用来把数字做好看。</li><li style="margin-bottom:7px;"><b>%GRR 和公差占比回答的是不同问题。</b>公差很宽时，公差占比可以很舒服，而对过程变差的 %GRR 却很差——当这张图被用来发现小偏移时，这一点就要命。</li><li style="margin-bottom:7px;"><b>重复性与再现性告诉你该往哪儿使劲。</b>EV 高指向量具、装夹或分辨率；AV 高指向操作手法、培训或测量方法定义不清；显著的操作员×零件交互，通常说明方法在不同零件上被用成了不同做法。</li><li style="margin-bottom:7px;"><b>GR&amp;R 只是一项研究，不是整个 MSA。</b>偏倚、线性、稳定性，以及计数型量具的一致性研究是另外几项。破坏性试验、化学分析或视觉检测系统需要完全不同的设计。</li></ul>
<p style="background:#fff8e8;border:1px solid #f0d9a0;border-radius:8px;padding:11px 15px;margin:0 0 16px;font-size:14px;"><b>实务提示。</b> 分辨率仍然重要：一台只能读到 0.1 mm 的量具，无法令人信服地支撑一场针对 0.05 mm 散布的研究。现行 MSA 参考资料已用更细致的指导取代了旧的「10:1 经验法则」——请查实际分辨率和得到的可区分类别数，不要凭记忆背一个比值。</p>
<h2 id="s3" style="font-size:20px;margin-top:30px;margin-bottom:8px;">结果落在边缘时怎么办</h2>
<ol style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:9px;">先查试验设计：零件选取、随机化、盲测，以及操作员是否都按同一份定义好的方法操作。</li><li style="margin-bottom:9px;">看 ANOVA 表，判断问题在设备还是在人——两种改法完全不同。</li><li style="margin-bottom:9px;">如果 10–30% 确实属于有条件接受，把理由写清楚：特性关键度、客户同意、改进成本，以及采取了哪些附加控制（例如重复读数取平均）。</li><li style="margin-bottom:9px;">量具、夹具或方法一旦改过，重做研究。MSA 结果属于某个具体系统，不是永久挂在零件号上的。</li></ol>
<h2 id="where-it-goes-wrong" style="font-size:20px;margin-top:30px;margin-bottom:8px;">现场最容易踩的坑</h2>
<p style="margin:0 0 11px;">把 10% 和 30% 当成标准里的合格／不合格要求。它们是广泛使用的 AIAG MSA 惯例，顾客特殊要求可能另定阈值。</p>
<p style="margin:0 0 11px;">挑十个几乎一样的零件，把 %GRR 抬高，然后启动一个本不需要的换量具项目。</p>
<p style="margin:0 0 11px;">客户要的是对总变差的 %GRR，你报了公差占比（或反过来），还不说明用的是哪个分母。</p>
<p style="margin:0 0 11px;">让操作员互相看着读数，或按零件顺序而不是随机顺序测量——两者都会悄悄毁掉研究的独立性。</p>
<p style="margin:0 0 11px;">做完一次就再也不重做，哪怕换了夹具、换了一批操作员或修过量具。</p>
<h2 id="faq" style="font-size:20px;margin-top:30px;margin-bottom:8px;">常见问题</h2>
<p style="margin:0 0 10px;"><b>10% / 30% 写在 ISO 9001 或 IATF 16949 里吗？</b><br>没有。它们出自 AIAG MSA 参考手册（及等效的客户参考资料），通过顾客特殊要求、PPAP 提交和控制计划落地。标准要求的是适宜的测量资源和有效的结果，数字分档属于惯例。</p>
<p style="margin:0 0 10px;"><b>ndc 是什么，为什么重要？</b><br>可区分类别数（也称可区分数据类数）估计测量系统在观测变差范围内能可靠区分多少个组。小于 2 表示系统分不清产品；用于过程控制的量具通常期望 ≥ 5。</p>
<p style="margin:0 0 10px;"><b>可以不改量具，改成多次读数取平均吗？</b><br>有时可以——重复测量取平均会减小重复性分量，但必须写进测量方法、始终一致地执行，并反映在控制计划里。它解决不了再现性问题，也解决不了分辨率不足。</p>
<p style="margin:0 0 10px;"><b>GR&amp;R 多久重做一次？</b><br>没有统一周期。量具、夹具、方法、操作员群体或特性发生变化时，客户要求时，以及控制计划／顾客特殊要求规定的频次，都应重做。</p>
