<h1 style="font-size:29px;line-height:1.25;margin:14px 0 6px;">怎么过 ISO/IEC 17025 现场评审：评审员真正追的是哪条链</h1>
<p style="color:#5b6675;font-size:15px;margin:0 0 6px;">评审员不会把你的手册从头读到尾。他们抽一份已签发的报告，把证据链往前、往后各走一遍。</p>
<p style="color:#8a94a3;font-size:12px;margin:0 0 16px;">更新于 2026 年 11 月 13 日 · 约 9 分钟 · 写给一线实验室与质量团队</p>
<div style="background:#eef4ff;border-left:4px solid #1e4d8b;border-radius:8px;padding:14px 18px;margin:0 0 22px;"><p style="margin:0 0 6px;font-size:11px;font-weight:700;letter-spacing:.6px;color:#1e4d8b;text-transform:uppercase;">短答案</p><p style="margin:0;font-size:15px;">通过 17025 评审的关键，是能把一份已签发的报告从头到尾复原出来：合同评审、方法及其版本号、原始记录、签发人针对该具体范围的能力授权、设备当时的校准状态、报告值背后的不确定度预算，以及任何合格／不合格结论背后的书面判定规则。评审员靠纵向追溯和现场见证工作，不是靠欣赏一套程序文件。</p></div>
<div style="border:1px solid #e6e9ef;border-radius:8px;padding:12px 16px;margin:0 0 24px;"><p style="margin:0 0 6px;font-size:12px;font-weight:700;color:#5b6675;">本页目录</p><ol style="margin:0;padding-left:20px;font-size:13.5px;"><li><a href="#s1" style="color:#2563eb;">到访之前必须已经成立的六件事</a></li><li><a href="#s2" style="color:#2563eb;">评审当天实际发生什么</a></li><li><a href="#s3" style="color:#2563eb;">纵向追溯，一步一步走</a></li><li><a href="#s4" style="color:#2563eb;">哪些条款最容易开出不符合项</a></li><li><a href="#s5" style="color:#2563eb;">末次会议之后</a></li><li><a href="#where-it-goes-wrong" style="color:#2563eb;">现场最容易踩的坑</a></li><li><a href="#faq" style="color:#2563eb;">常见问题</a></li></ol></div>
<h2 id="s1" style="font-size:20px;margin-top:30px;margin-bottom:8px;">到访之前必须已经成立的六件事</h2>
<ol style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:9px;"><b>一轮完整自查已经闭环。</b>覆盖全部条款的内审（8.8）和一次管理评审（8.9），每项输入都要有定义、有支撑证据——不是一份只列议题的会议纪要。</li><li style="margin-bottom:9px;"><b>范围已冻结且诚实。</b>认可范围上每一个方法／基质／被测量，背后都有确认或验证证据（7.2）；申请书上的范围要和实验室实际出具的报告一致。</li><li style="margin-bottom:9px;"><b>方法已在本实验室确认可用。</b> 已发布的标准方法仍需验证：你的人、你的仪器、你的基质能否达到方法声称的性能（7.2.1.3）。非标、修改过或自研方法需要按预期用途做确认，参数要选得合适（7.2.2）。</li><li style="margin-bottom:9px;"><b>每个被测量都有不确定度预算，判定规则已成文。</b>条款 7.6 要求评定测量不确定度；7.8.6 要求只要报告符合性声明，就必须有书面判定规则，并在合同评审（7.1.3）时与客户约定。</li><li style="margin-bottom:9px;"><b>溯源链是真的查过。</b>手里有一张认可机构供应商的校准证书还不够（6.4 / 6.5）。必须有人核实到 SI 的链条、证书上的 CMC，以及证书有效期是否覆盖测量当天。</li><li style="margin-bottom:9px;"><b>能力授权做到范围级，能力验证异常已处置。</b>报告签发人必须被授权做「这个方法＋这个基质」（6.2），并有持续监控。能力验证／实验室间比对出现不满意结果却没有书面调查，是 7.7 下最常见的不符合项之一。</li></ol>
<h2 id="s2" style="font-size:20px;margin-top:30px;margin-bottom:8px;">评审当天实际发生什么</h2>
<div style="overflow-x:auto;margin:0 0 16px;"><table style="width:100%;border-collapse:collapse;font-size:13.5px;"><thead><tr><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">评审活动</th><th style="border:1px solid #e6e9ef;padding:8px 10px;text-align:left;background:#f3f6fb;">真正在考的是什么</th></tr></thead><tbody><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">首次会议与范围确认</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">约定范围、场所、签发人是否与现实一致</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">文件与记录审查</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">版本受控，以及记录能否证明程序确实被执行</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">实验室巡查</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">设备状态标识、环境控制、样品完整性、会影响结果的现场管理</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">现场见证／演示</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">分析人员是否真会做这个方法，原始记录是否按程序当场生成</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">从一份已签发报告做纵向追溯</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">整条证据链往前、往后（见下一节）</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">人员面谈</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">能力、公正性，以及对判定规则的理解</td></tr><tr><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">末次会议</td><td style="border:1px solid #e6e9ef;padding:8px 10px;vertical-align:top;">不符合项逐条对应条款，并附支撑证据</td></tr></tbody></table></div>
<p style="background:#fff8e8;border:1px solid #f0d9a0;border-radius:8px;padding:11px 15px;margin:0 0 16px;font-size:14px;"><b>实务提示。</b> 见证试验是最容易让漂亮文件露馅的地方。如果技术员伸手去拿一张写着「实际做法」的便利贴，那么受控文件里的方法就不是真方法——不管文件做得多好，这就是一条不符合项。</p>
<h2 id="s3" style="font-size:20px;margin-top:30px;margin-bottom:8px;">纵向追溯，一步一步走</h2>
<p style="margin:0 0 12px;">评审前让自己人先做一次演练：递给他一份上个月签发的报告，要求十分钟内拿出：</p>
<ol style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:9px;">委托／合同评审记录，其中与客户约定了方法和判定规则（7.1）。</li><li style="margin-bottom:9px;">样品接收、状态和标识记录（7.3 / 7.4）。</li><li style="margin-bottom:9px;">当天生效的方法确切版本，及其验证／确认档案（7.2）。</li><li style="margin-bottom:9px;">含原始观察值、更正痕迹和更正人的技术记录（7.5）。</li><li style="margin-bottom:9px;">所用每台仪器的校准状态与溯源证据（6.4 / 6.5）。</li><li style="margin-bottom:9px;">产出报告上那个不确定度的预算表（7.6）——包括每个分量的来源。</li><li style="margin-bottom:9px;">若报告有符合性声明，拿出书面判定规则（7.8.6）。</li><li style="margin-bottom:9px;">报告签发人针对该方法、该基质的授权记录（6.2）。</li><li style="margin-bottom:9px;">证明当天结果有效的质控／能力验证证据（7.7）。</li></ol>
<p style="background:#fff8e8;border:1px solid #f0d9a0;border-radius:8px;padding:11px 15px;margin:0 0 16px;font-size:14px;"><b>实务提示。</b> 任何一环找了二十分钟，评审员都会注意到。常见失败不是「文件缺失」，而是「文件接不上」：签发人的授权早于方法改版、不确定度预算与报告模板对不上、校准证书收到后从未确认。</p>
<h2 id="s4" style="font-size:20px;margin-top:30px;margin-bottom:8px;">哪些条款最容易开出不符合项</h2>
<p style="margin:0 0 12px;">两个必须记准的基本事实：现行标准是 <b>ISO/IEC 17025:2017</b>，没有 2025 版，转卖资料的标题怎么写都不算数；<b>2026 年 1 月 1 日起 Global ACI 取代 IAF 与 ILAC</b>，成为统一的国际认可组织，旧文件正按 Global ACI 编号重新发布。请以自己认可机构现行文件清单为准，不要凭记忆引用老的 ILAC-Gx 编号。</p>
<ul style="margin:0 0 14px;padding-left:22px;"><li style="margin-bottom:7px;"><b>6.2 / 6.4 / 6.5</b>——能力与授权只做到岗位级；设备适用性；校准链从未被复核。</li><li style="margin-bottom:7px;"><b>7.2</b>——确认档案证明了技术可行，却不是实验室实际出具报告所针对的基质和浓度范围。</li><li style="margin-bottom:7px;"><b>7.6 / 7.8.6</b>——把校准证书的扩展不确定度直接抄成预算；有合格／不合格结论却无书面判定规则；报告写「±」却不写 k 和包含概率。</li><li style="margin-bottom:7px;"><b>7.7 / 8.8 / 8.9</b>——一次能力验证不满意结果没有调查；内审按日历排而不是按风险排；管理评审输入没有证据。</li><li style="margin-bottom:7px;"><b>8.5 / 8.7</b>——纠正措施做完，风险登记册从不重新评估；纠正措施以「已重新培训人员」结案，没有有效性验证。</li></ul>
<h2 id="s5" style="font-size:20px;margin-top:30px;margin-bottom:8px;">末次会议之后</h2>
<p style="margin:0 0 12px;">不符合项会对应到条款并附客观证据。每一条都要：先控制即时影响，再查根因（包括是否波及其他报告或范围），纠正这一个具体案例，然后验证有效性，并约定复查日期。答复窗口由认可机构规定，视严重程度常为 30–90 天。「错别字已改」只能关闭错别字，关不掉体系性弱点；如果根因会让同样的错误在另一份报告上重演，评审员会重新开这条不符合项。</p>
<h2 id="where-it-goes-wrong" style="font-size:20px;margin-top:30px;margin-bottom:8px;">现场最容易踩的坑</h2>
<p style="margin:0 0 11px;">到访前一周重写质量手册。被评审的不是手册，是证据链。</p>
<p style="margin:0 0 11px;">把「我们用的是标准方法」当成免验证的豁免。7.2.1.3 仍要求你证实本实验室能达到该方法的性能。</p>
<p style="margin:0 0 11px;">授权矩阵在岗位级是最新的、在范围级却过期——签发人授权早于方法改版，或持续监控已中断。</p>
<p style="margin:0 0 11px;">把校准证书上的扩展不确定度 U 当成整份预算，或当作标准不确定度使用却没除以证书写明的 k。</p>
<p style="margin:0 0 11px;">能力验证不满意结果只归档一句「已调查，无影响」，没有根因分析、没有趋势分析。</p>
<h2 id="faq" style="font-size:20px;margin-top:30px;margin-bottom:8px;">常见问题</h2>
<p style="margin:0 0 10px;"><b>ISO/IEC 17025:2017 还要求质量手册吗？</b><br>不要求。2017 版在方案 A 下规定管理体系要求（若已按 ISO 9001 运行管理体系，可走方案 B），但没有强制一份叫「质量手册」的文件。很多实验室保留它，是因为客户或历史合同要求。</p>
<p style="margin:0 0 10px;"><b>什么是判定规则，什么时候必须有？</b><br>判定规则说明在做出符合规范的结论时如何计入测量不确定度（条款 7.8.6，定义见 3.7）。只要报告写合格／不合格、在允差内、符合，就必须有书面规则、在合同评审时与客户约定（7.1.3）并予以沟通。如果只报告数值及其不确定度，就没有作出符合性声明。</p>
<p style="margin:0 0 10px;"><b>现场评审要多久？</b><br>取决于范围、方法数、场所和技术评审员人数——范围窄的一天，多领域实验室可能一周以上。关键是范围上每个方法都能被见证或追溯；提前向认可机构索取评审计划。</p>
<p style="margin:0 0 10px;"><b>可以远程或混合评审吗？</b><br>不少认可机构按自身规则和现行 Global ACI 过渡文件，允许部分文件审查或访谈在异地完成，但技术活动见证通常仍须到场。安排方式请与自己的认可机构书面确认。</p>
